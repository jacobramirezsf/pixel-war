# Pixel War

A pixel-art real-time strategy game, being rebuilt from a single-file prototype into a real project.

## Read these in order

1. **`BRIEF.md`** is the build brief. Paste its contents below the divider into Claude Code as the first message.
2. **`legacy/README.md`** covers the prototype, what is verified, and what is known broken.
3. **`docs/conquest.md`** specifies the persistent territory mode. It is milestones M7 and M8 and it is the eventual point of the project. Read it early, apply the five structural notes at the end of it while working through the earlier milestones, and do not build the mode before M7.

## Layout

```
BRIEF.md                 the build brief
docs/conquest.md         persistent world mode design
legacy/
  README.md              prototype notes and verification status
  pixel-war-v3.html      current build, the one to port
  pixel-war-v2.html      previous version, reference only
  tests/                 headless assertions the prototype passes
```
